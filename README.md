# 同频 · X → 币安广场

<img src="extension/icons/icon128.png" alt="同频" width="80" height="80">

在电脑 Chrome 发布 X 帖子，按你的设置同步到币安广场。纯本机 Chrome Manifest V3 插件，无需服务器，也不需要 X API Key。

[下载最新版安装包](https://github.com/fh199601-oss/samewave-x-to-binance-square/releases/latest) · [作者 X：@shangshuss](https://x.com/shangshuss) · [MIT 开源许可](LICENSE) · [隐私说明](PRIVACY.md)

## 安装

1. 在上面的 Releases 页面下载 `samewave-chrome-v1.0.4.zip` 并解压，将得到的「同频-Chrome插件」文件夹放在固定位置。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，直接选择整个 **「同频-Chrome插件」文件夹**，不用进入子文件夹。如果下载的是 GitHub 源码 ZIP，也直接选择解压后的仓库根目录。
4. 打开「同频」工作台，填入 X 用户名（@ 后的英文名）以及币安广场发帖 API Key。
5. 选择同步类型，开启「自动同步」，点击「保存设置」。
6. **刷新已有的 X 标签页**。以后在这个 Chrome 中照常发帖即可。

从工具栏「扩展程序」菜单固定同频，可以随时查看状态和打开工作台。Mac、Windows 均可安装，不需要运行本项目中的开发脚本。不要删除或移动已加载的整个目录。

### 已经安装旧版本

下载新版本，将文件覆盖到原安装文件夹。打开 `chrome://extensions`，找到同频点击「重新加载」，然后刷新设置页和 X 页面。保持原来的加载路径，可以保留已保存的账号、API 与去重记录。旧版的 extension 子目录加载方式仍兼容，无需卸载；不要同时开启两个同频，否则可能重复同步。

v1.0.4 在小面板右下角、工作台左下角增加作者 X 主页入口，并以 MIT 许可公开源码。安装包和源码都不包含任何人的 API Key、Chrome 数据或同步记录。

v1.0.2 重载或更新时不再自动打开设置页，仅首次安装会打开。

v1.0.3 在工具栏小面板加入「自动同步」开关，立即保存并与工作台同步，不必进入工作台。API 检测不再占用入队队列。增加发布前临时网络错误的有限重试、任务批次校验、成功回执补记、暂停后恢复以及未确认入队时的页面提示。

v1.0.1 修正了 Chrome 原生 fetch 需要绑定 Window / WorkerGlobalScope 的调用问题。旧版本会把 `Illegal invocation` 错误误显示为网络失败。检测结果现在会持续显示在 API 字段下，能区分连接超时、网络/权限错误、HTTP 网关响应和币安业务错误。

## 账号与 API

- 每个人填写自己的 X 用户名及广场 API。发布目标由 API 对应的广场账号决定，不需要额外填写广场 UID。
- 广场 API 从[创作者中心](https://www.binance.com/square/creator-center/home)获取，**不是币安交易 API**。
- 「检测连接」仅申请一个未上传的图片上传凭据，不发布任何测试内容；该请求可能计入平台接口额度。
- 密钥只存在当前 Chrome 配置文件的扩展本地存储，不写入项目代码，不使用 Chrome 云同步，不会被导出。
- 分享安装包即可，收件人首次打开时账号和 API 均为空，自动同步关闭。
- 「导出偏好」包含 X 用户名与规则，不含 API；导入后需要检查、保存并手动开启同步。

## 同步行为

| 选项 | 行为 |
| --- | --- |
| 原创帖子 | 默认开启，保持正文内容，带上原帖媒体 |
| 引用帖子 | 默认关闭；开启后同步你的正文及自身附件，追加被引用帖链接 |
| 回复与串文 | 默认关闭；开启后每条回复单独同步，附上所回复帖链接 |
| 纯转发 | 默认关闭；开启后分享原帖链接，不复制原作者正文和附件 |
| 纯文字 / 图片帖 / 视频帖 | 分别决定是否同步整条帖子；关闭后不会降级成缺少附件的文字 |
| 附上 X 原帖链接 | 可选，默认关闭 |

X 成功返回新帖后才进入队列；浏览旧帖、失败的发布请求不会入队。插件只接受配置账号的新发布，并保存去重记录。安装前的帖子不补发，手机、其他浏览器和 X 服务端定时发布不会自动捕捉。修改或删除 X 帖子不会同步修改广场内容。

图片最多 4 张；视频或 GIF 动图转换视频最多 1 个。视频使用 X 返回的最高码率 MP4 和原视频封面，时长缺失时在本机解析。为了限制本机内存占用，单张图片上限 20 MiB，视频上限 512 MiB，这属于本插件限制，不代表币安的官方限制。

投票、X 文章、图片视频混发、多视频和不完整媒体会提示处理，不会静默丢弃附件。普通长帖使用完整正文，最终字数限制以币安接口返回为准，超限会显示错误，不自动截断。

## 同步失败与重复保护

- **等待自动重试**：仅发布之前的临时网络故障、媒体接口 429/5xx 等，会等待 30 秒、2 分钟、5 分钟，最多自动重试三次。实际时间受 Chrome 定时器与电脑休眠影响。不重试已经发送的发布请求。
- **需处理**：接口明确拒绝、附件格式不支持或有限重试仍失败。修复原因后点「重试」。
- **待核对**：发布请求超时、HTTP 5xx、响应异常，或浏览器在发布中关闭。请求可能已经成功；先到广场查看，已发则点击「确认已在广场发布」，未发再「核对后重试」。
- **已忽略**：你决定不发该条；保留去重记录。
- 自动同步暂停后，不再捕捉新帖，也不会开始新的发布；已经发送给币安的请求无法撤回。暂停时尚未发布的任务保留在队列，重新开启后继续。
- 有未完成、失败或待核对任务时，先处理或忽略这些任务，再更换账号或 API，避免旧内容发布到新账号。

队列持久化，媒体处理由扩展后台文档负责；请保持 Chrome 运行直到完成。插件每分钟检查未完成任务，发布前中断可以恢复，发布后结果不明不会自动重发。币安官方接口未提供本工具可用的幂等键或发帖查询能力，因此无法保证网络异常情况下的严格「恰好一次」，此时需要人工核对。

去重 ID 持续保留，记录界面最多保留最近 500 条已结束任务及未处理任务。卸载扩展会清除密钥、设置、记录和去重 ID。不要用卸载来解决发布结果不明的问题。

## 开发与验证

Node.js 18.17+，无 npm 依赖。先克隆仓库或下载源码：

```sh
npm test
npm run check
node scripts/preview.mjs
npm run pack
```

预览地址为 `http://127.0.0.1:8786/options.html`，预览页不会储存 API 或发布内容。打包脚本在 macOS 使用系统 zip，将根 manifest、extension 代码、说明、隐私说明和许可证放进单一外层文件夹。源文件修改后 `npm run pack` 会生成新版外层 manifest 并核对资源路径。

测试覆盖：帖文解析、账号/类型过滤、图片视频流程、凭据隔离、并发去重、队列串行、关闭恢复、有限重试、过期任务消息、回执丢失、快速暂停与恢复、跨页面状态同步。所有自动化网络测试使用模拟响应，**不等同于所有真实网络状况下都已验证**。安装后应以你实际发布的新帖确认当前账号的同步结果。

X 没有为浏览器插件提供稳定的「发布成功」事件。本插件被动观察当前页面的 CreateTweet / CreateNoteTweet / CreateRetweet 响应，不保存 Cookie，不调用未授权的额外 X 接口。X 更改页面和数据结构时需要更新适配。原始回复缺少必要字段时会提示未识别，而不是猜测内容。
