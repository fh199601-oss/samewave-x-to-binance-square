WELCOME TO SAMEWAVE

三分钟，开始同频

  1. 打开 Chrome 扩展程序管理页，启用「开发者模式」。
  2. 点击「加载已解压的扩展程序」，直接选择解压后的整个「同频-Chrome插件」文件夹。
  3. 填写 X 用户名和广场 API，选择同步偏好，打开「自动同步」并保存。
  4. 刷新已打开的 X 页面，之后照常发帖。

不必进入任何子文件夹。分享给朋友时发送安装压缩包即可，密钥只保存在各自 Chrome 中。

已经安装旧版时，在扩展管理页点击同频的「重新加载」，然后刷新设置页即可保留设置。请勿同时启用两份同频，以免重复发送。

目前支持最多 4 张图片或 1 个视频；投票、混合媒体和 X 文章会暂停提示。未完成同步时请保持 Chrome 打开。

网页接口变化可能需要更新插件。移除插件会同时移除本机设置和去重记录。
